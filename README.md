# MyContentsChecker

여러 스트리밍 서비스에 흩어진 시청 진척도, 회차별 별점과 감상을 한곳에서 관리하는 브라우저 기반 로컬 앱입니다. 서버 계정 없이 작동하므로, 데모는 GitHub Pages에 그대로 배포할 수 있습니다.

## 데모 경험

처음 방문한 브라우저에는 실제 작품을 바탕으로 한 7개의 데모 콘텐츠, 시청 진척도, 별점, 감상이 자동으로 표시됩니다. 초기 목록은 **나의 해방일지**, **더 베어**, **듄: 파트 2**, **장송의 프리렌**, **무빙**, **고독한 미식가**, **푸른 눈의 사무라이**로 구성했습니다.

각 작품은 실제 공개일·제작 국가·전체 회차 수와 대표 회차 정보를 담습니다. 초기 로딩을 가볍게 유지하기 위해 장편 시리즈는 전 회차가 아닌 대표 회차만 저장하며, 상세 화면에 이 사실을 표시합니다. 표지는 TMDB 이미지 CDN 또는 공식 배급사 자료에서 불러오므로 인터넷 연결이 필요합니다. 출처 표기는 앱의 **설정 → 데이터 출처**에서 확인할 수 있습니다.

기존에 사용하던 라이브러리가 있으면 데모 초기 데이터가 이를 덮어쓰지 않습니다. **설정 → 데모 데이터 초기화**를 선택한 경우에만 데모의 초기 상태로 되돌립니다.

## 실행

의존성 설치는 필요하지 않습니다. 외부 API 검색까지 확인하려면 로컬 서버로 실행하세요.

```powershell
python -m http.server 8000
```

이후 `http://localhost:8000`을 최신 Chrome 또는 Edge에서 엽니다.

## 사용 방법

1. 메인에서 데모 콘텐츠의 진척도와 별점을 확인합니다.
2. 콘텐츠 상세에서 회차를 펼쳐 시청 체크, 별점, 감상을 관리합니다.
3. 필요하면 **설정**에서 자신의 TMDB API Read Access Token을 입력합니다.
4. **콘텐츠 찾기**에서 한국어·일본어·영어 제목을 검색합니다.

토큰과 모든 개인 기록은 해당 브라우저·도메인의 `localStorage`에만 저장됩니다. 토큰을 소스 파일, Git 커밋, 이슈, README 예시에 넣으면 안 됩니다.

## 핵심 기능

- TMDB 우선, TVmaze 폴백의 영화·드라마·애니메이션 검색
- 시즌/회차별 시청 상태와 1~5점 별점
- 작성 시각이 남는 감상 댓글, 인라인 수정, 삭제 확인
- 회차의 오래된 순/최신 순 정렬과 다중 시즌 접기/펼치기
- 라이브러리 검색·시청 상태 필터·30일 보관 휴지통
- 데스크톱 사이드바 및 모바일 하단 메뉴 반응형 UI

## 프로젝트 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 접근 가능한 화면 골격과 확인 대화상자 |
| `app.js` | 저장소, 공급자 폴백, 렌더링과 이벤트 처리 |
| `demo-data.js` | 실제 작품 메타데이터와 대표 회차를 담은 7개 포트폴리오 샘플 |
| `styles.css` / `portfolio.css` | 기본 레이아웃과 포트폴리오 반응형 보정 |
| `.github/workflows/deploy-pages.yml` | `main` 푸시 시 GitHub Pages 배포 |

상세 규격은 [요구사항](./docs/REQUIREMENTS.md), [아키텍처](./docs/ARCHITECTURE.md), [디버깅 가이드](./docs/DEBUGGING.md), [수동 테스트 기록](./docs/TESTING.md), [GitHub Pages 배포 가이드](./docs/DEPLOYMENT.md)를 참고하세요.

## 검증

```powershell
node --check app.js
node --check demo-data.js
```

브라우저 수동 검증 범위와 결과는 [테스트 기록](./docs/TESTING.md)에 정리했습니다.

## 제약 사항

- 로그인·서버 동기화·서비스별 자동 진척도 연동은 아직 제공하지 않습니다.
- 일부 TMDB 작품은 한국어 회차 설명·포스터가 없을 수 있습니다.
- TVmaze는 영문권 TV 콘텐츠에 상대적으로 강합니다.
