# 디버깅 가이드

## 빠른 점검

1. 개발자 도구 Console에서 자바스크립트 오류를 확인한다.
2. Network에서 `api.themoviedb.org` 요청의 상태 코드와 `Authorization` 헤더 형식을 확인한다.
3. 설정 화면에서 토큰이 연결됨 상태인지 확인한다.
4. 문제가 재현되면 Application → Local Storage에서 `mcc-*` 키를 백업한다.

## 흔한 문제

| 증상 | 원인/조치 |
| --- | --- |
| TMDB 검색 결과 없음 | 토큰 만료·오입력 여부 확인, TVmaze 폴백 결과 확인 |
| 상세 등록 실패 | Network의 TV/영화 상세 요청 확인; 캐시를 유지한 채 다시 시도 |
| 오래된 UI 표시 | 강력 새로고침(Ctrl+F5), 스크립트 로딩 순서 확인 |
| 데이터가 사라짐 | 다른 브라우저 프로필/시크릿 모드인지 확인 |
| 토큰 노출 | TMDB에서 즉시 폐기하고 새 토큰 발급 |
