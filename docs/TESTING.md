## 배포 전 추가 확인 권장

- 실제 TMDB Read Access Token을 통한 한국어·일본 애니메이션 검색
- Firefox·Safari에서의 시각 회귀

## 반복 절차

1. 로컬 서버를 시작하고 시크릿 창 또는 새 프로필에서 연다.
2. 설정에서 테스트 전용 TMDB 토큰을 입력한다.
3. 한국어 드라마, 영화, 일본 애니메이션을 각각 검색한다.
4. 한 작품을 등록하고 회차·댓글·별점·정렬을 확인한다.
5. 휴지통 이동과 복원을 확인한 뒤 개발용 저장소 데이터를 제거한다.
