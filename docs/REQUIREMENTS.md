# 제품 요구사항

## 목표

사용자가 서비스별 시청 기록의 단절 없이 개인 콘텐츠 라이브러리를 관리한다.

## 기능 요구사항

### 콘텐츠 데이터

- TMDB를 우선 공급자로 사용하고 `ko-KR` 메타데이터를 요청한다.
- TMDB 검색 또는 상세 조회 실패 시 TVmaze를 시도한다.
- 콘텐츠는 제목, 유형, 제작 국가, 방영일, 줄거리, 이미지, 시즌, 에피소드로 정규화한다.
- 영화는 단일 에피소드로 표현한다.

### 라이브러리와 회차

- 콘텐츠 등록, 조회, 휴지통 이동, 복원, 영구 삭제를 제공한다.
- 삭제한 항목은 30일 후 앱 실행 시 자동 정리한다.
- 자동 정리와 영구 삭제는 해당 콘텐츠의 캐시·댓글도 함께 제거한다.
- 회차별 시청 완료, 별점, 감상 댓글을 저장한다.
- 댓글은 작성 시각을 표시하고 인라인 수정/삭제 확인을 제공한다.
- 상세 화면은 시즌별로 묶되 시즌이 하나면 시즌 헤더를 숨긴다.

### 비기능 요구사항

- 개인정보와 토큰은 서버로 저장하지 않는다.
- 첫 방문자는 외부 API나 토큰 없이도 7개 샘플로 기능을 이해할 수 있다.
- 외부 API 실패는 기존 캐시와 최소 콘텐츠 폴백으로 견딘다.
- 최신 Chrome/Edge의 데스크톱과 390px 이상 모바일 폭을 지원 대상으로 한다.

## 수용 기준

- 한국어 제목 검색 결과에서 영화/드라마/애니메이션 유형을 확인할 수 있다.
- 토큰 미설정 또는 TMDB 장애 시 TVmaze 검색을 시도한다.
- 댓글 저장·수정·삭제 시 현재 회차 패널과 스크롤 위치가 유지된다.
- 등록/삭제/복원 후 명시적 페이지 새로고침 없이 UI가 갱신된다.
